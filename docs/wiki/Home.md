# Добро пожаловать в CookPal Wiki

**CookPal** — мобильное приложение «Кулинарный помощник», разработанное на Kotlin с Jetpack Compose.

## Возможности

- Учёт продуктов
- Поиск рецептов по API Spoonacular
- Избранные рецепты
- Список покупок
