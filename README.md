# CookPal — Кулинарный помощник

**CookPal** — это мобильное приложение для Android, разработанное на Kotlin с использованием Jetpack Compose. Оно помогает пользователю вести учёт продуктов, искать рецепты через API Spoonacular, сохранять избранные рецепты и формировать список покупок.

## Функциональность

- Учёт продуктов (добавление, удаление свайпом, просмотр)
- Поиск рецептов по названию через Spoonacular API
- Просмотр деталей рецепта (ингредиенты, инструкция, изображение)
- Добавление рецептов в избранное
- Формирование списка покупок с автоматическим выявлением недостающих ингредиентов
- Перенос купленных продуктов в общий список продуктов

## Технологический стек

- **Язык:** Kotlin 100%
- **UI:** Jetpack Compose, Material 3, Navigation Compose
- **Архитектура:** MVVM, ViewModel + StateFlow
- **База данных:** Room (3 таблицы)
- **Сеть:** Retrofit 2 + Moshi, API Spoonacular
- **Многопоточность:** Kotlin Coroutines
- **DI:** Ручное внедрение (AppContainer)
- **Тестирование:** JUnit 4, MockK, Compose Testing

## Установка

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/your-org/cookpal.git
   ```
2. Откройте проект в Android Studio.
3. Получите API-ключ на [spoonacular.com/food-api](https://spoonacular.com/food-api).
4. Укажите ключ в файле `local.properties`:
   ```
   SPOONACULAR_API_KEY=your_api_key_here
   ```
5. Соберите и запустите приложение.

## Использование

1. **Мои продукты** — добавьте продукты через FAB, удаляйте свайпом влево.
2. **Поиск рецептов** — введите название блюда, получите результаты в виде сетки.
3. **Детали рецепта** — нажмите на карточку, чтобы увидеть ингредиенты и инструкцию.
4. **Избранное и покупки** — сохраняйте рецепты, управляйте списком покупок.
